# hartsoft.dev

Source code for [hartsoft.dev](https://hartsoft.dev), the portfolio site of Lee Hart.

Built with [Astro](https://astro.build) and hosted on [Cloudflare Workers](https://workers.cloudflare.com).

## Local development

Requires Node.js 22 or later.

```sh
npm ci
npm run dev
```

To build the site:

```sh
npm run build
```
