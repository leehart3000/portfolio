statinfer brings classic statistical hypothesis tests to modern JavaScript and TypeScript. It works in Node.js and in the browser, and every test takes a single options object and returns the same result format: the test statistic, p-value, degrees of freedom, estimate and confidence interval.

Version 0.1 includes t-tests (one-sample, paired and two-sample), proportion tests, chi-square tests, Pearson and Spearman correlation tests, one-way ANOVA and Fisher's exact test, plus a `summarize` function for readable output. Rank-based tests and linear regression are on the roadmap.

Accuracy comes first: every test is checked against SciPy or statsmodels to about 10 decimal places, using reference values generated by a Python script managed with uv. The library is written in TypeScript, bundled with tsdown (built on Rolldown), and tested with Vitest. GitHub Actions runs linting, type checking, tests and documentation builds on every change, while TruffleHog and Snyk scan for leaked secrets and vulnerable dependencies.

- Package: [statinfer on npm](https://www.npmjs.com/package/statinfer)
- Interactive demo: [statinfer.vercel.app](https://statinfer.vercel.app/), built with Next.js and hosted on Vercel, with a "which test should I use?" guide and plain-language explanations of results
- API documentation: [leehart3000.github.io/statinfer](https://leehart3000.github.io/statinfer/), generated by TypeDoc and hosted on GitHub Pages
