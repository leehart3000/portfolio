Panoptes lets researchers explore large datasets in the browser, with tools for querying, sorting and plotting tabular data, and for building templated views and pages around it. For genomic data in particular, it includes a genome browser, a genotype viewer, maps of geographic data and phylogenetic tree views. It was used to share and explore data from projects such as the *Anopheles gambiae* 1000 Genomes project (Ag1000G).

I contributed to Panoptes while working at the University of Oxford. My work included:

- Developing features in the React front end, including interactive maps, charts and data tables
- Developing the Python back end, which served data from a MonetDB database through Gunicorn
- Working with the front-end build and tooling
- Fixing bugs and helping users publish their datasets.
